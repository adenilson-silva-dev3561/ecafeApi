ECafe API - Ordem de Desenvolvimento dos Endpoints

=========================================
FASE 1 - CATEGORY
=================

POST   /api/v1/categories
GET    /api/v1/categories
GET    /api/v1/categories/{id}
PUT    /api/v1/categories/{id}
DELETE /api/v1/categories/{id}

Objetivo:

* Cadastrar categorias
* Listar categorias
* Atualizar categorias
* Remover categorias

Exemplos:
Coffee
Peanuts
Rapadura
Candy
Kits

=========================================
FASE 2 - PRODUCT
================

POST   /api/v1/products
GET    /api/v1/products
GET    /api/v1/products/{id}
GET    /api/v1/products/category/{categoryId}
PUT    /api/v1/products/{id}
DELETE /api/v1/products/{id}

Objetivo:

* Cadastrar produtos
* Listar produtos
* Buscar por categoria
* Atualizar produtos
* Remover produtos

Exemplos:
Coffee Premium
Coffee Gourmet
Roasted Peanuts
Rapadura

=========================================

FASE 4 - CART
=============

POST   /api/v1/carts

GET    /api/v1/carts/{id}

GET    /api/v1/carts/customer/{customerId}

POST   /api/v1/carts/{cartId}/items

PUT    /api/v1/carts/{cartId}/items/{itemId}

DELETE /api/v1/carts/{cartId}/items/{itemId}

DELETE /api/v1/carts/{cartId}/clear

Objetivo:

* Criar carrinho
* Adicionar produtos
* Remover produtos
* Atualizar quantidade
* Limpar carrinho
